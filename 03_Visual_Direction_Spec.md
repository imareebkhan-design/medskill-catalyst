# Visual Direction Spec — give this to Claude design alongside the prompt

**Read first:** This describes *structure and treatment*. **Colors, fonts and logo come from my saved MedSkills Catalyst brand system** — apply those tokens to the roles below. The hex codes here are only functional placeholders to show intent; replace with brand equivalents.

---

## 1. Color roles (map to brand tokens)
| Function | Use | Placeholder |
|---|---|---|
| Base / background | Role slides — calm, light, high-contrast for text | light paper |
| Ink / text | Headlines + body | brand dark/navy |
| Primary accent | Difficulty bar fill, counters, eyebrows, "no engineering" tag | brand primary (e.g. teal) |
| Highlight accent | Open-loop line, ribbon, CTA word, "engineering needed" tag | brand secondary (e.g. coral/orange) |
| Bookends | Cover + CTA = inverted (dark background, light text) so the set has visual "doors" | brand dark |

Rule: **one base, two accents, nothing else.** No gradients, no neon, no stock photos.

## 2. Typography hierarchy (use brand fonts)
- **Cover headline:** largest on the slide, bold, tight leading (~1.05), slightly negative tracking.
- **Role name:** second-largest, bold.
- **One-liner / sub:** medium weight, muted ink, generous leading (~1.35).
- **Labels (eyebrow, "WHY…", counter, footer):** small, uppercase, letter-spaced, accent color.
- Only **two type sizes of "loud"** per slide max. Everything else recedes.

## 3. Layout grid (all slides)
- Outer margin ~8% (≈ 84–88 px on 1080). Nothing touches the edge.
- Consistent zones: **TOP** (wordmark left + counter right), **BODY** (the one idea), **BOTTOM** (difficulty + tag), **FOOTER** (microcopy + swipe cue).
- Vertical rhythm consistent slide-to-slide so swiping feels stable, not jumpy.

## 4. Reusable components (build once, reuse on all 7 role slides)
- **Progress counter:** "ROLE 03 / 07", top-right, accent color, letter-spaced.
- **Difficulty bar:** 5 equal blocks in a row; filled blocks = primary accent, empty = light grey. Always paired with a word label ("Very low / Low / Moderate / High / Very high") and the heading "Entry difficulty".
- **Engineering tag:** pill. "No engineering degree" = primary-accent soft fill. "Engineering degree needed" = highlight-accent soft fill. Keep both pills identical in size/shape.
- **"Why your pharma background counts" box:** a card with a thick left border in primary accent, soft shadow, one sentence inside. This is the emotional anchor — make it visually distinct on every role slide.
- **Ribbon (2 roles only):** small solid highlight-accent tag, "UNDERRATED · one of the 2 easiest entries", placed above the role name.
- **Footer microcopy:** "Honest assessment, not a placement claim" — small, muted. (Trust signal; keep it.)

## 5. Cover & CTA treatment (the bookends)
- **Cover:** dark background, big headline, open-loop line in highlight accent, swipe cue bottom-left. One subtle brand-accent shape (e.g. a soft circle) for depth — nothing busy.
- **CTA:** same dark background for symmetry. The word "MAP" set as a highlight-accent pill with wide letter-spacing so it reads as the one action. One CTA only.

## 6. Mobile legibility & "screenshot test"
- Assume a 6-inch screen. If a line wouldn't be readable at thumbnail size in the feed, it's too small.
- Each slide must make sense as a standalone screenshot (people screenshot to save/share).
- High contrast between text and background everywhere (aim WCAG AA).

## 7. Do / Don't
**Do:** one idea per slide · consistent components · big type · whitespace · accent used sparingly for emphasis · progress counter on every role slide.
**Don't:** two roles on one slide · paragraphs of body text · multiple CTAs · salary numbers · decorative icons that add noise · changing layout between role slides.

## 8. Slide count logic
9 slides (cover + 7 roles + CTA) sits in the proven 6–9 band and matches the "7 items" promise. If you ever need to trim to fewer slides, merge the CTA payoff lines — never merge two roles onto one slide.
