## B. Specific things to copy from each (your visual checklist)

| Element | What good looks like | Where to see it |
|---|---|---|
| **Cover hook** | One bold line, massive type, open loop | Contentdrips hook images |
| **One idea per slide** | A single role/point owns the whole frame | Buffer #3 (Alex Smith) |
| **Numbered/ranked rhythm** | "1 of 7" expectation set on cover | Buffer #3 |
| **Restraint in design** | Dark bg, one big number/idea, minimal copy | Carouselli "Personal Journey" |
| **Summary/payoff slide** | Wrap-up slide before CTA | Carouselli + Buffer "summary slide" tip |
| **Single clear CTA** | One ask on the last slide | All three |

## C. The numbers that justify the format (context, not for screenshotting)
- Carousels: highest engagement format on LinkedIn; **~585% better than text posts** (Buffer, 52M+ posts).
- Multi-slide posts: **~3.4x reach, ~2.1x engagement** vs single image.
- **7 slides** reported as a sweet spot; **6–9** is the safe band.
- Checklist/reference content hits **~3x the average save rate** — saves are the #1 algorithmic signal.
- Completion rate for well-structured carousels averages **~36%** — the hook and progress counters protect this.
